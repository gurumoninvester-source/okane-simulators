プライバシーポリシー

「okane-uploader」（以下「本アプリ」）は、運営者本人の YouTube チャンネルへ動画をアップロードするためだけに使用される、個人用のツールです。本アプリのプライバシーに関する方針を以下に定めます。

取得する情報

本アプリは、YouTube Data API v3 を通じて、運営者本人の Google アカウントに対する OAuth 認証情報（アクセストークンおよびリフレッシュトークン）を取得します。それ以外の個人情報は取得しません。

情報の利用目的

取得した認証情報は、運営者本人のチャンネルへの動画アップロードおよび公開予約のためにのみ使用します。第三者への提供、販売、広告目的での利用は一切行いません。

情報の保管

認証情報は運営者の管理する機器内にのみ保管され、外部のサーバーへ送信されることはありません。

第三者への提供

取得した情報を第三者に提供することはありません。

お問い合わせ

本ポリシーに関するお問い合わせは、運営者の YouTube チャンネル「お金を考えすぎる会社員」の概要欄に記載の連絡先までお願いいたします。
